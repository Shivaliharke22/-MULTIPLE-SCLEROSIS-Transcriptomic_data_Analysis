# -MULTIPLE-SCLEROSIS-Transcriptomic_data_Analysis
Multiple Sclerosis (MS) is a chronic autoimmune disease affecting the central nervous system. 
Identifying reliable biomarkers is crucial for early diagnosis, prognosis, and therapeutic targeting.

This project implements a comprehensive bioinformatics workflow to identify potential biomarkers using gene expression datasets. 
The pipeline integrates differential expression, pathway enrichment, protein interaction networks, Immunoinfilteration analysis, and co-expression analysis.

# Objectives
Identify Differentially Expressed Genes (DEGs) between MS and control samples
Discover enriched biological pathways and functions
Construct Protein-Protein Interaction (PPI) networks
Detect hub genes with high biological significance
Analyze gene co-expression modules and their relationship with clinical traits
